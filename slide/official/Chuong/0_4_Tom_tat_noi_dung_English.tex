\begin{center}
    \Large{\textbf{ABSTRACT}}\\
\end{center}
\vspace{1cm}

The boom of digital art has driven a massive demand for specialized online image-sharing platforms. However, existing systems often struggle to moderate harmful content at scale, prevent artwork plagiarism, and provide intelligent semantic search instead of relying solely on traditional hashtags. Furthermore, executing computationally heavy tasks directly on the main request path can easily cause system bottlenecks and degrade user experience. To address these limitations, this thesis adopts an approach that constructs the system based on a modular architecture combined with an asynchronous background queue mechanism to optimize performance and ensure flexible scalability. On this basis, a platform for sharing and storing digital artworks integrating multimodal search technology has been developed using Next.js for the frontend and NestJS for backend services, utilizing PostgreSQL as the relational database and Meilisearch for optimized full-text search. The system integrates Clerk for authentication and Stripe to handle paid membership models for creators. The technological highlight of this solution lies in applying the CLIP model to generate vector embeddings for semantic search via pgvector, utilizing the Perceptual Hashing (pHash) algorithm for duplicate image detection, and integrating NSFWJS for automated sensitive content classification. All of these intensive processes are coordinated asynchronously by BullMQ and Redis to free up the main execution path. The main contribution of this thesis is the proposal and successful implementation of a practical distributed architecture that harmoniously balances user experience, financial rights for creators, and automated administration efficiency. The final outcome is a complete system framework that operates stably with low latency and effectively meets real-world operational requirements.
